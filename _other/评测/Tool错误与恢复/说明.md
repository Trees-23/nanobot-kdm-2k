# Tool 错误与恢复评测

本主题验证 Tool 从 Runner 失败归一化、Audit Event、恢复证据、Graph API 到 WebUI 的端到端契约。
重点是所有新异常终态都有安全错误诊断，并严格区分 retry、continuation 和 recovery。

当前协议版本为 `V1`：

- `V1/试卷.md`：固定输入、硬断言、评分和结论契约。
- `V1/监考提示词.md`：真实 Gateway、Chromium、测试矩阵和归档流程。
- `V1/运行记录/`：每次正式执行的新证据，不修改历史记录。

权威证据依次为 Runtime Event、受保护 Graph API、真实浏览器 DOM/请求监听和聚焦自动化测试。
Graph 或 WebUI 不得按时间、Tool 名、basename 或错误文本推测恢复关系。
