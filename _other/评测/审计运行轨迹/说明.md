# nanobot 审计运行轨迹专项评测

本主题用于验证运行轨迹从 Runner、Audit Event、Graph API 到 WebUI 的结构化错误诊断、显式
恢复证据、原始 Event 导航、Payload 安全读取、关系聚焦和时间线滚动。

## 当前版本

当前使用 V3：

```text
V3/试卷.md
V3/监考提示词.md
```

把 `V3/监考提示词.md` 整段交给监考 AI。监考器先按 V3 manifest 将固定 fixture 部署到实际
Agent workspace，再由 `V3/prompt_send.py` 从试卷提取并原子发送唯一输入，在真实 WebUI 新建
Session，并把证据写入 `V3/运行记录/<时间戳>/`。

`V1/更新清单.md` 是设计速记和场景索引，不是权威评分契约；发生冲突时以同版本试卷为准。
`V2/更新清单.md` 记录 V1 到 V2 的部署修复；`V3/更新清单.md` 记录输入原子性修复。更新清单
不替代同版本试卷的权威断言。

## 版本规则

`V1`、`V2`、`V3` 和后续 `Vn` 表示评测协议版本，不表示第几次考试。V2 增加 Agent workspace
fixture 部署；V3 增加固定的多行输入原子发送协议。改变输入、评分、硬断言、证据结构、fixture
语义、安全边界或部署契约时创建新版本目录；只修正错别字且不改变语义时可在当前版本修订。

旧版本一经用于正式评测即冻结，不原地改写历史试卷、监考提示词、fixture 或运行记录。每次实际
考试只新增一个时间戳运行记录目录。

## 文件归属

| 文件类型 | 生成者 | 存放位置 |
|---|---|---|
| 主题说明 | 评测设计者 | `审计运行轨迹/说明.md` |
| 试卷与唯一 Agent 输入 | 评测设计者 | `Vn/试卷.md` |
| 监考执行说明 | 评测设计者 | `Vn/监考提示词.md` |
| 设计速记 | 评测设计者 | `Vn/更新清单.md` |
| 固定测试输入 | 评测设计者 | `Vn/fixtures/` |
| Agent workspace fixture 部署 | 监考器 | 由 `Vn/fixture_stage.py` 写入同版本指定的 workspace 目标目录 |
| 唯一输入摘要与发送协议 | 评测设计者 | `Vn/prompt-manifest.json` 与 `Vn/prompt_send.py`（适用于 V3 及后续版本） |
| 证据、截图和评分 | 监考器 | `Vn/运行记录/<时间戳>/` |
| 权威 Audit | nanobot runtime | runtime Audit 存储，不复制或修改到本目录 |

不要把试卷、提示词、更新清单或 fixture 裸放在 `_other/评测/` 根目录。
