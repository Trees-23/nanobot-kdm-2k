# nanobot 子智能体终止与恢复综合试卷 V2

版本：2026-08-02。V1 已冻结；本版是协议升级，不是重跑编号。

时限：前检 10 分钟；正式运行 30 分钟；终态稳定观察和归档 10 分钟。

## 一、评测对象

真实链路必须至少覆盖：

```text
Gateway -> AgentLoop -> Runner -> Tool/Subagent/Process executor -> durable orchestration
        -> Audit emitter/indexer -> Graph/Events API -> 同一部署 dist -> Chromium
```

禁止以 mock、直接 seed 生命周期 Event、线程池、`task.cancel()` 返回、发送 kill 请求或合成页面冒充目标能力。
Linux/容器关键场景不得 skip/xfail。读取链路 fixture 可以用于浏览器回归，但不能作为 Runtime 最终证据。

## 二、环境和安全门禁

开考前确认 HEAD、镜像 ID、配置解析后的 workspace/audit root、WebSocket、Audit index、Chromium 和
本版本 fixture SHA-256。监考用 Gateway 配置必须显式设置 `agents.defaults.failOnToolError=false`，仅用于
本场受控正例；不得修改产品默认值或生产配置。不得归档 secret、token、cookie、完整 prompt、Tool 参数、
Payload、PID 命令行或用户文件内容。

PID 仅作诊断。kill 前必须同时验证 executor ID、process instance identity、supervisor identity 和启动证据；
身份不匹配时必须拒绝。Payload endpoint 在用户显式点击前请求数为 0。
