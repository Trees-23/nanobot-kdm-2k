## 二、运行与重启

从真实 spawn 返回中提取 task/child Run ID。四项任务登记且 tool-recovery 形成真实终态后，重建本场 Gateway，
不得用 `/stop` 取消整个 task_group。指定 child 的协作取消、grace、TERM/KILL process group、root exit、
wait/reap、后代检查和 fd/pipe 清理以本场正式真实进程 suite 为权威证据；suite 无法确认退出时记
`termination_failed/lost`，不得写 timed_out/cancelled。


`webui/e2e/generate-audit-tool-recovery-runtime.py` 经真实 `AgentRunner + ReadFileTool + AuditRuntime`
